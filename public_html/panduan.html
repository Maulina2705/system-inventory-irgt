BUKU PANDUAN PENGGUNAAN
SISTEM INVENTARIS ASET IT

Pedoman komprehensif pengelolaan siklus hidup perangkat, tiket pelaporan maintenance, pemindaian label QR Code, serta kontrol akses kredensial pengguna terpusat di lingkungan IRGT School.

Instansi: IRGT School
Departemen: Tim IT Infrastructure
Versi: 1.0 (Production)
Tahun: 2026

1. Pengenalan & Struktur Wewenang (Role Akun)

Sistem Inventaris IRGT dirancang untuk mencatat seluruh perangkat teknologi (Laptop, PC, Proyektor, Router, Printer, dll.), memfasilitasi pelaporan kendala secara cepat oleh guru/staf, dan mengelola alur kerja perbaikan oleh teknisi IT.

Tiga Tingkat Wewenang (Role-Based Access Control)

Role Hak Akses Utama Fungsi & Tanggung Jawab
SUPER ADMIN Akses Penuh (Full Access) Mengelola seluruh master data inventaris, mengelola wewenang akun user, melihat/mengubah password pengguna, melakukan reset password default, serta menghapus data.
ADMIN (IT) Petugas / Teknisi IT Menginput aset baru, mengubah status perangkat, mencetak QR Code, dan memproses laporan maintenance (*In Progress* & *Resolved*).
USER (PELAPOR) Guru, Karyawan, Siswa Mengajukan laporan kendala perangkat (disertai foto bukti) dan memantau status pengerjaan tiket miliknya secara *real-time*. Tidak dapat mengedit data inventaris internal.
Catatan Kebijakan Akun Baru: Setiap pengguna yang mendaftar melalui halaman registrasi otomatis mendapatkan role User (Pelapor). Jika pengguna tersebut adalah staf IT, Super Admin dapat menaikkan wewenangnya menjadi Admin (IT) di menu Kelola Pengguna.

2. Rincian & Fungsi Masing-Masing Tab Halaman

A. Tab "Daftar Inventaris" (`/assets`) — Khusus Admin & Super Admin

Merupakan dashboard utama pusat data perangkat sekolah dengan kapabilitas:

Pencarian & Multi-Filter

Memfilter data berdasarkan kata kunci nama/kode aset, penempatan ruangan, kategori unit, kondisi fisik, dan status operasional.

Modal Preview QR Code

Klik tombol QR Code pada baris aset untuk melihat kode visual, mencetak langsung label stiker, atau mengunduh file gambar PNG.

Audit History Cepat

Tombol riwayat untuk melacak kronologi lengkap perbaikan dan perpindahan perangkat dari awal didaftarkan.

Cetak Massal (Print Label)

Fitur cetak label stiker inventaris berstandar barcode scanner untuk ditempelkan pada bodi fisik perangkat.

B. Tab "Tambah Data Inventaris" (`/assets/create`) — Khusus Admin & Super Admin

Formulir pendaftaran unit baru ke dalam database:

  • Kode Aset Unik: Format penomoran otomatis terstandarisasi (misal: IRGT-LAB-PC-001).
  • Spesifikasi & Serial Number: Merek, tipe model, prosesor, RAM, penyimpanan, dan nomor seri pabrikan.
  • Lokasi & Penempatan: Menentukan gedung, ruangan kelas, laboratorium, atau nama guru/penanggung jawab unit.
  • Kondisi Awal: Pilihan kondisi (Baik / Good, Cukup / Fair, Rusak / Damaged).

C. Tab "Laporan Maintenance" (`/reports`) — Tersedia untuk Semua User

Pusat antrean tiket kendala dan perbaikan perangkat. Tampilan menyesuaikan wewenang akun:

1

Pengajuan Laporan oleh User (Guru / Staf)

User memilih aset bermasalah (atau memindai QR pada bodi perangkat), menuliskan gejala kerusakan, dan melampirkan foto bukti (PNG / JPG). Foto akan otomatis dikompresi oleh sistem.

2

Penerimaan & Tindakan Teknisi IT

Petugas IT mengubah status tiket menjadi IN PROGRESS (Sedang Dikerjakan). Status aset di sistem otomatis berubah menjadi MAINTENANCE.

3

Penyelesaian Tiket & Audit Trail Otomatis

Setelah selesai diservis, teknisi mengklik RESOLVED (Selesai) serta mengisi catatan tindakan. Status aset otomatis kembali ACTIVE, dan histori tersimpan abadi beserta nama teknisi dan timestamp.

3. Panduan Menu "Kelola Pengguna" (`/users`) — Khusus Super Admin

Menu sentral bagi Super Admin untuk mengatur seluruh akun, wewenang, dan kredensial sistem:

Fitur Tampilan & Tombol Deskripsi Penggunaan
Lihat Password User Ikon Mata (`Show/Hide`) + Salin Super Admin dapat membuka samaran password pengguna lain untuk keperluan verifikasi atau bantuan login langsung.
Ubah Password Kustom Tombol Biru `Ubah Password` Membuka pop-up modal untuk memasukkan password baru pilihan, dilengkapi tombol acak dan dialog konfirmasi "Anda Yakin?" sebelum disimpan.
Reset Default (IRGTE165) Tombol Amber `Reset Default` Mengembalikan kata sandi akun terpilih kembali ke standar awal: IRGTE165 dengan notifikasi pop-up.
Ubah Role Akun Dropdown Select + Tombol `Ubah` Mengubah wewenang pengguna secara instan antara Super Admin, Admin IT, atau User Pelapor.
Hapus Akun Pengguna Tombol Merah `Hapus` Menghapus akun pengguna dari database (dilengkapi modal proteksi konfirmasi agar tidak terhapus tidak sengaja).

4. Halaman Publik & Pemindaian QR Code

A. Portal Inventaris Publik (`/public-assets`)

Halaman transparan yang dapat diakses oleh siapa saja tanpa perlu login, menyajikan ringkasan jumlah total aset sekolah, status unit yang aktif, serta perangkat yang sedang dalam masa perawatan.

B. Scan QR Code via Kamera Handphone (`/asset/scan/{token}`)

Ketika stiker QR Code pada bodi laptop/proyektor dipindai menggunakan kamera smartphone:

  • Halaman detail aset publik akan langsung terbuka secara responsif.
  • Terdapat tombol cepat "Ajukan Laporan Kerusakan" yang langsung mengarahkan user ke form tiket dengan aset yang sudah otomatis terpilih.

5. Keamanan Sistem & Panduan Pemeliharaan (Maintenance)

A. Arsitektur Keamanan yang Diterapkan

  • Server-Side Role Guard: Seluruh rute sensitif diverifikasi langsung di server PHP via middleware. Manipulasi kode di browser (*Inspect Element*) otomatis ditolak dengan HTTP 403 Forbidden.
  • Anti-Brute Force (Rate Limiting): Pembatasan percobaan login otomatis (maksimal 5x per menit) untuk mencegah pembobolan akun secara paksa.
  • Anti-SQL Injection & Anti-XSS: 100% Prepared Statements (Eloquent ORM) dan escaping karakter Blade {{ }}.
  • Penyembunyian File Sensitif: File .env, database SQL, log, dan source code diblokir total dari akses web melalui aturan .htaccess.

B. Cara Mengganti Logo Sekolah pada Navbar

Sistem telah dilengkapi pendeteksi logo otomatis. Anda cukup meletakkan file logo sekolah ke folder berikut:

Lokasi File: public/images/logo.png (atau public_html/images/logo.png)
Format yang Didukung: PNG, JPG, JPEG, atau SVG

Setelah file ditaruh, logo sekolah akan otomatis menggantikan ikon default di pojok kiri atas seluruh halaman.
