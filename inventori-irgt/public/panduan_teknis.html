01 Arsitektur Sistem & Stack Teknologi

Aplikasi dibangun dengan arsitektur Monolitik Terstruktur berbasis Laravel Framework, menerapkan prinsip Server-Side Rendering (SSR) via Blade Templates tanpa ketergantungan JavaScript framework yang berat untuk memaksimalkan kecepatan render, stabilitas koneksi, dan kemudahan deployment di shared-hosting cPanel maupun VPS.

Komponen Teknologi / Library Deskripsi & Peran Arsitektural
Backend Framework Laravel 11.x/12.x/13.x (PHP 8.4) Routing engine, Eloquent ORM, Service Container, CSRF Protection, dan Middleware pipeline.
Database Engine MySQL 8.0+ / MariaDB Storage transaksional dengan Foreign Key cascading, indeks unik untuk QR code tokens, dan InnoDB engine.
Authentication & RBAC Laravel Fortify (Custom RBAC) Sesi autentikasi aman, Password Hashing Bcrypt (rounds=12), rate limiting, dan role enforcement.
Image Processing Native PHP GD Extension MIME type validation, dynamic downscaling (max 1600px), dan JPEG quality compression (75%).
Session Driver SESSION_DRIVER=file Penyimpanan sesi berbasis file lokal untuk mencegah bottleneck MySQL "Too Many Connections (1040)" pada remote hosting.
Frontend Layer Blade, Vanilla JS, CSS Grid/Flexbox Desain responsif mobile-first, modal orchestration tanpa dependency jQuery/Bootstrap/React.

02 Skema Database & Relasi Antar Tabel (ERD)

Database terdiri dari tabel inti yang saling berelasi secara integritas referensial (FK constraints):

1. Tabel `users` (Pengguna & Hak Akses)

CREATE TABLE `users` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `name` VARCHAR(255) NOT NULL,
  `email` VARCHAR(255) UNIQUE NOT NULL,
  `password` VARCHAR(255) NOT NULL,         -- Bcrypt hash
  `plain_password` VARCHAR(255) NULL,          -- Plaintext tracking untuk Super Admin
  `role` ENUM('super_admin','admin','user') DEFAULT 'user',
  `remember_token` VARCHAR(100) NULL,
  `created_at` TIMESTAMP NULL,
  `updated_at` TIMESTAMP NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

2. Tabel `assets` (Master Data Inventaris)

CREATE TABLE `assets` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `asset_code` VARCHAR(100) UNIQUE NOT NULL,   -- Contoh: IRGT-PC-001
  `name` VARCHAR(255) NOT NULL,
  `category` VARCHAR(100) NOT NULL,           -- Laptop, PC, Proyektor, dll
  `brand` VARCHAR(100) NULL,
  `model` VARCHAR(100) NULL,
  `serial_number` VARCHAR(150) NULL,
  `location` VARCHAR(255) NOT NULL,          -- Ruang Guru, Lab Komputer, dll
  `status` ENUM('active','maintenance','damaged','disposed') DEFAULT 'active',
  `condition` ENUM('good','fair','damaged') DEFAULT 'good',
  `purchase_date` DATE NULL,
  `purchase_cost` DECIMAL(15,2) NULL,
  `vendor` VARCHAR(255) NULL,
  `warranty_expiry` DATE NULL,
  `ownership` VARCHAR(150) DEFAULT 'IRGT School',
  `scan_token` VARCHAR(64) UNIQUE NOT NULL,    -- Token acak aman untuk URL scan publik
  `notes` TEXT NULL,
  `created_at` TIMESTAMP NULL,
  `updated_at` TIMESTAMP NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

3. Tabel `maintenance_reports` (Tiket Pelaporan & Maintenance)

CREATE TABLE `maintenance_reports` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `report_number` VARCHAR(50) UNIQUE NOT NULL, -- Format: REP-202608-XXXX
  `asset_id` BIGINT UNSIGNED NULL,
  `user_id` BIGINT UNSIGNED NOT NULL,
  `reporter_name` VARCHAR(255) NOT NULL,
  `reporter_email` VARCHAR(255) NOT NULL,
  `location` VARCHAR(255) NOT NULL,
  `issue_description` TEXT NOT NULL,
  `priority` ENUM('low','medium','high','urgent') DEFAULT 'medium',
  `status` ENUM('pending','in_progress','resolved','rejected') DEFAULT 'pending',
  `photo_path` VARCHAR(255) NULL,
  `handled_by` BIGINT UNSIGNED NULL,
  `resolution_notes` TEXT NULL,
  `resolved_at` TIMESTAMP NULL,
  `created_at` TIMESTAMP NULL,
  `updated_at` TIMESTAMP NULL,
  FOREIGN KEY (`asset_id`) REFERENCES `assets`(`id`) ON DELETE SET NULL,
  FOREIGN KEY (`user_id`) REFERENCES `users`(`id`) ON DELETE CASCADE,
  FOREIGN KEY (`handled_by`) REFERENCES `users`(`id`) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

4. Tabel `asset_histories` (Audit Trail & Kronologi Aset)

CREATE TABLE `asset_histories` (
  `id` BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `asset_id` BIGINT UNSIGNED NOT NULL,
  `action_type` VARCHAR(50) NOT NULL,          -- created, updated, maintenance, repaired
  `description` TEXT NOT NULL,
  `performed_by` VARCHAR(255) NOT NULL,        -- Nama user / teknisi
  `created_at` TIMESTAMP NULL,
  FOREIGN KEY (`asset_id`) REFERENCES `assets`(`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

04 State Machine Siklus Laporan & Sinkronisasi Aset

Ketika tiket laporan maintenance diubah statusnya oleh petugas IT, controller secara otomatis menjalankan transaksi ganda pada tabel maintenance_reports, tabel assets, dan tabel asset_histories:

// MaintenanceReportController.php: updateStatus()
switch ($newStatus) {
    case 'in_progress':
        $report->update([
            'status' => 'in_progress',
            'handled_by' => auth()->id(),
        ]);
        // Aset otomatis diubah ke status 'maintenance'
        $report->asset?->update(['status' => 'maintenance']);
        break;

    case 'resolved':
        $report->update([
            'status' => 'resolved',
            'handled_by' => auth()->id(),
            'resolved_at' => now(),
            'resolution_notes' => $request->resolution_notes,
        ]);
        // Aset otomatis dikembalikan ke status 'active' & 'good'
        $report->asset?->update([
            'status' => 'active',
            'condition' => 'good'
        ]);
        // Audit trail tersimpan ke riwayat aset
        $report->asset?->histories()->create([
            'action_type' => 'repaired',
            'description' => "Perbaikan selesai oleh " . auth()->user()->name . ": {$request->resolution_notes}",
            'performed_by' => auth()->user()->name,
        ]);
        break;
}

05 Pipeline Pemrosesan & Kompresi Gambar (GD)

Untuk menghemat kuota hosting dan mencegah eksploitasi file webshell berkedok gambar, upload foto melewati pipeline pembersihan dan kompresi native GD:

/**
 * Pipeline Kompresi & Resize Otomatis via PHP GD
 */
private function compressAndStoreImage($file): string
{
    $extension = strtolower($file->getClientOriginalExtension());
    $sourcePath = $file->getRealPath();

    // 1. Baca gambar asli sesuai format MIME
    $image = match ($extension) {
        'png'  => imagecreatefrompng($sourcePath),
        default => imagecreatefromjpeg($sourcePath),
    };

    // 2. Hitung dimensi proporsional (Maksimal Lebar/Tinggi 1600px)
    $maxDim = 1600;
    if ($origW > $maxDim || $origH > $maxDim) {
        $ratio = min($maxDim / $origW, $maxDim / $origH);
        $newW = (int) round($origW * $ratio);
        $newH = (int) round($origH * $ratio);
        $canvas = imagecreatetruecolor($newW, $newH);
        imagecopyresampled($canvas, $image, 0, 0, 0, 0, $newW, $newH, $origW, $origH);
        $image = $canvas;
    }

    // 3. Simpan sebagai file JPEG bersih terkompresi (Quality 75%)
    $filename = 'report_' . time() . '_' . Str::random(8) . '.jpg';
    imagejpeg($image, storage_path('app/public/reports/' . $filename), 75);
    imagedestroy($image);

    return 'reports/' . $filename;
}
